# NextCare MX - Week 5 Submission Bundle

This folder contains the runnable NextCare MX prototype and its supporting evidence. It is a static HTML/CSS/JavaScript project and uses only fictional data.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. No API keys, database, build step, or installation are required for the prototype itself.

## Test

Run `node test.js` from this folder. The captured passing result is in `test-evidence/MECHANICAL_TEST_RESULTS.txt`.

## Product boundary

NextCare MX begins with an existing provider-approved screening result. It does not diagnose, interpret raw medical data, recommend treatment, determine urgency, or guarantee access. The AI text is simulated and labeled. After two unsuccessful automated contacts, automation stops. A human navigator may accept ownership, but the case remains unresolved until a valid outcome occurs.

## Submission files

The three required PDFs are one directory above this folder. `DEMO_SCRIPT.md` is the recording guide, and `SUBMISSION_CHECKLIST.md` separates completed work from the two genuinely manual deliverables: the student's own video and the copied live URL.
