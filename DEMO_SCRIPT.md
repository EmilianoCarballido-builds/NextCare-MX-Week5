# DEMO_EmilianoCarballido.mp4 - Recording Guide

Target length: 2-3 minutes. Record the live site after deployment if possible; the local `index.html` works as a backup for rehearsal.

## Before recording

- Open the site at desktop width and close unrelated tabs or notifications.
- Confirm the top banner says `FICTIONAL DEMO` and the AI card says `SIMULATED AI OUTPUT`.
- Click `Reset demo` so attempts display `0 of 2`.
- Use your own voice and screen recording. Name the final file exactly `DEMO_EmilianoCarballido.mp4`.

## Spoken script and clicks

1. **Opening (15-20 seconds)**

   "This is NextCare MX, a fictional Week 5 prototype. It does not diagnose or provide medical advice. It starts with an existing provider-approved abnormal screening result and helps move that result toward an accountable next action."

2. **Show the structured handoff (20-30 seconds)**

   Point to the fictional case and say:

   "The handoff tracks the next action, owner, deadline, status, barrier, contact attempts, and escalation. The simulated AI output only explains approved information in plain language. It does not choose treatment or determine urgency."

3. **First unsuccessful attempt (15 seconds)**

   Click `Record unsuccessful contact attempt` once.

   "The first unsuccessful attempt is recorded. The attempt count is now one, and one more automated follow-up is allowed."

4. **Second unsuccessful attempt and escalation (20 seconds)**

   Click the same button a second time.

   "After the second unsuccessful attempt, automation stops. The case changes to HUMAN REVIEW REQUIRED, and the navigator dashboard shows that the case is blocked."

5. **Human acceptance stays unresolved (20 seconds)**

   Click `Accept unresolved case`.

   "The human navigator now owns the handoff, but acceptance is not the same as completed care. The status says ACCEPTED - STILL UNRESOLVED until the approved clinical next action is confirmed, redirected by a clinician, or the patient makes an informed opt-out."

6. **Reflection (25-35 seconds)**

   "What changed my mind this week was realizing that better AI detection is not necessarily the biggest problem. If someone gets an abnormal result but has no clear path to actual care, better detection can create fear earlier. I therefore built NextCare MX around the gap between detection and action, with honest statuses and a required human handoff when automation fails."

7. **Closing (10 seconds)**

   "All patient information and AI output shown here are simulated. This prototype makes no diagnosis, treatment recommendation, appointment guarantee, or coverage promise."

## Required visible proof

- Fictional-patient banner
- Simulated-AI label
- Structured handoff fields
- Attempts changing 0 -> 1 -> 2
- `HUMAN REVIEW REQUIRED`
- Disabled automated-attempt button after attempt 2
- `ACCEPTED - STILL UNRESOLVED`
